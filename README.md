# Smart Parking Reservation System

A Smart Parking Reservation System built using Java, Spring Boot, and MySQL.

## Features
- View available and reserved parking slots
- Reserve a parking slot
- Calculate parking fees
- Track reservation start and end times
- Admin dashboard to view booking history and revenue

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- HTML and CSS

## Project Setup
1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Configure your MySQL database in `application.properties`.
4. Run `SmartParkingApplication.java`.
5. Open `http://localhost:8080` in your browser.
